- Design revision: back up the current brief to `.ctx/.brief.prev.md`.
- Implementation: `src/cli.js` copies the prior brief before rewriting when content changes.
- Doctor check: compares current and previous brief line counts and warns when the current brief is less than half the previous version.
- Result: correctly adopted.

### HIGH-2: Two-Section Inbox And Archive Rules

- Design revision: define `## Pending` and `## Archived` sections.
- Implementation: `parseInbox`, `archiveInbox`, and `splitArchiveBlocks` implement the two-section structure and retain the newest 20 archive blocks.

## 5. Findings

### Critical

- None.

### High

#### HIGH-1: `doctor` Initially Had No Test Coverage

- File: `test/cli.test.js`
- Problem: the first test suite covered `init`, `update`, and `pack`, but did not cover `doctor`, dry run, notes input, missing `.ctx`, brief truncation, or non-git fallback.
- Impact: `doctor` is one of the four MVP commands and is responsible for context health checks.
- Fix: tests were expanded to cover healthy `doctor`, missing files, suspicious brief shrinkage, dry run, notes, missing `.ctx`, and brief truncation.

### Medium

#### MEDIUM-1: Proposal Dedupe Initially Included The Date

- Problem: proposal titles included the update date and the initial hash depended on title plus body, so identical content could produce duplicates across days.
- Impact: repeated updates could accumulate duplicate proposals.
- Fix: proposal hash now uses stable content (`type + body`), and a cross-date dedupe test was added.

#### MEDIUM-2: Generated Config Included Planned Fields

- Problem: `config.yaml` included `sources` and `update` sections that were not yet read by the implementation.
- Impact: users might assume those controls were active.
- Fix: the template marks those sections as planned but not yet implemented.

### Low

#### LOW-1: Duplicate Unknown-Command Branch

- Problem: the default switch branch had equivalent error paths.
- Fix: the duplicate branch was removed and an unknown-command test was added.

#### LOW-2: Pack Markdown Proposal Count Was Bare

- Problem: markdown output showed only a raw number.
- Fix: output now uses `N pending proposal(s)` and has test coverage.

#### LOW-3: Empty Inbox Formatting Had Extra Blank Lines

- Problem: an empty Pending section created excess spacing.
- Fix: `formatInbox` now conditionally emits pending content.
